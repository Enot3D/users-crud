Авторизация
===========

В .env добавьте JWT_SECRET — случайную строку минимум из 32 символов.
Сгенерировать: uv run python -c "import secrets; print(secrets.token_hex(32))"
JWT_TTL_MINUTES задаёт срок действия токена (по умолчанию 30 минут).

Для существующей базы перед запуском выполните:
uv run python -m app.migrate

POST /users теперь требует password длиной от 8 до 128 символов.
POST /auth/login принимает email и password и возвращает access_token.
В Swagger нажмите Authorize и вставьте полученный токен.
PATCH и DELETE /users/{id} доступны только владельцу записи.
Без действительного токена возвращается 401, для чужой записи — 403.
GET и создание пользователя остаются открытыми.

Старые записи сохраняются, но вход для них недоступен: у них нет пароля.
Создайте нового пользователя с паролем. Назначать пароль старой записи
следует отдельно после проверки владельца, а не через открытый API.
